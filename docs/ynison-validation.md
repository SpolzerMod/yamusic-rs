# Ynison: журнал проверки

Дата: 2026-11-25. ОС: Windows 11 Pro x64, build 26300.
CPU: AMD Ryzen 7 5700X, 8 ядер / 16 логических процессоров.
ОЗУ: около 32 ГиБ. Rust: 1.100.0, MSVC x86_64.
Baseline commit: `6de1b03ccfbce8335d3fa20583b91493ef1fda4c`.

## Автоматические проверки

`cargo test --locked`: **42 passed, 0 failed, 4 ignored** в последнем завершённом
прогоне. Финальные сборки и повторная проверка после последних исправлений запущены;
их итог будет дополнен после завершения.

Проверены:

- компиляция общего Rust-кода и нового интерфейса Slint на Windows;
- регистрационный JSON видимого player и строковые protobuf int64;
- monotonic versions и сохранение неизвестного queue context;
- разбор shuffle без смещения текущего трека, отклонение неверных индексов;
- неподдерживаемый контент не приводит к проигрыванию другого индекса;
- host redirect не может указывать на произвольный внешний сайт;
- watch заменяет накопленные обновления последним;
- локальный WebSocket: Ping и текстовое состояние;
- cancellation сетевого worker;
- устаревшие epoch/revision не применяются;
- удалённая громкость и потеря ownership не вызывают command echo;
- существующие тесты плеера, API, UI helpers и других подсистем.

Ignored-тесты зависят от аккаунта, внешнего сервиса или ручного окружения.
Это не тесты взаимодействия с официальным телефоном.

## Производительность

Результаты реальных замеров ещё не получены. Release baseline и новая сборка
собираются. Для измерения без пользовательских настроек предусмотрен
`scripts/measure-release-pair.ps1`: три последовательных запуска в отдельных
APPDATA-профилях, 30 секунд прогрева, затем 120 секунд idle в трее.

**Сценарий без входа не запускает соединение Ynison даже при включённой настройке.**
Он измеряет только регрессию неавторизованного idle и не позволяет подтвердить
целевые дополнительные 5–15 МБ для активного соединения.

Не измерены: активный signed-in Connect, воспроизведение, latency команд с телефона,
время старта до готового интерфейса, длительный рост памяти/handles после reconnect.

## Что пока не подтверждено

- Реальное обнаружение компьютера официальным клиентом.
- Play/pause, next/previous, seek, volume, queue, repeat/shuffle между телефоном и RS.
- Перенос воспроизведения и синхронизация позиции на production-сервисе.
- Восстановление после реального сетевого разрыва и отзыва токена.
- Накладные расходы RAM/CPU с активным соединением, отсутствие audio/startup regressions.
- Linux и Android.

Интеграция экспериментальная; перечисленные пункты не объявляются успешно
пройденными. Сценарий ручной проверки: [ynison.md](ynison.md).
