# Скачивание треков

1. Откройте Настройки и включите «Неофициальные настройки» (после эквалайзера).
2. Включите «Скачивание треков».
3. Выберите MP3 или FLAC, размер обложки 400/600/800/1000 пикселей.
   Для MP3 доступны 192 и 320 кбит/с; для FLAC битрейт определяется аудиоданными.
4. Нажмите значок скачивания перед сердечком в строке трека. Он доступен во всех
   списках: плейлистах, альбомах, поиске, подборках, чартах, на страницах исполнителей
   и в очереди воспроизведения. Нажатие добавляет трек в очередь скачивания и не
   запускает воспроизведение. Также доступны «Скачать» в меню и кнопка в шапке списка.
5. Значок перед кнопками управления окном открывает компактную панель очереди:
   «Исполнитель — Название» в одну строку, прогрессбар и значок папки справа.
   Панель появляется поверх страницы, сохраняет фокус ввода и позволяет добавлять
   следующие треки одним нажатием. Повторное нажатие значка очереди закрывает панель.
6. После завершения скачивания значок папки открывает Проводник с выделенным файлом.

Используются существующие компоненты настроек и тема приложения. Обработка аудио
встроена в Rust, отдельный FFmpeg не требуется. MP3 получает ID3v2.3, FLAC — Vorbis
comments и PICTURE. Аудиоданные FLAC извлекаются из MP4 без перекодирования.

Папка: `Music/Яндекс Музыка`, для списков — подкаталог с названием списка.
ID трека и параметры в имени различают одинаковые названия и варианты качества.
Настройки скачивания не меняют качество воспроизведения. Выбранный недоступный
вариант возвращает ошибку; приложение не подменяет его другим форматом.

Одна общая очередь обрабатывает задания последовательно. Новые задания можно
добавлять, пока предыдущие скачиваются. Параметры каждого задания фиксируются при
добавлении. Выключение переключателя запрещает новые задания; уже добавленные
завершаются. Очередь не восстанавливается после перезапуска. Журнал временных файлов
в папке данных приложения позволяет удалить остатки прерванных загрузок на следующем
запуске. Готовые файлы сохраняются.

Для полного трека нужны аккаунт и доступ к этому треку. Серверные варианты качества
могут зависеть от аккаунта и каталога. Авторизация и воспроизведение работают как раньше.
