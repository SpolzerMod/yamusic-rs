# Интеграция macOS

Системный слой находится в `src/sys/macos/`. `mod.rs` сохраняет интерфейс `sys`,
которым пользуются общие модули приложения. `window.rs` содержит операции с окном
и темой, `instance.rs` — сокет повторного запуска, `autostart.rs` — пока прежние
заглушки автозапуска.

## Команды и время жизни

`commands.rs` определяет `MacCommand`, клонируемый `CommandSender` и владельца
`MacIntegration`. Владелец создаётся `gui::install_macos()` в главном потоке и
сохраняется до завершения Slint event loop. `MainThreadMarker` не позволяет
перенести владельца будущих нативных ресурсов на другой поток.

Отправитель использует `Weak::upgrade_in_event_loop`: фоновый обработчик не
обращается к интерфейсу напрямую и не удерживает окно сильной ссылкой. Флаг
времени жизни проверяется перед постановкой команды в очередь и непосредственно
перед выполнением. При уничтожении `MacIntegration` отложенные команды
отзываются. В `gui::run()` владелец явно уничтожается до `process::exit`, который
сам не вызывает Rust-деструкторы.

Пока подключён только источник ShowWindow — повторный запуск через сокет.
Остальные варианты протокола подготовлены для меню и MediaPlayer. Поведение
крестика не меняется: он по-прежнему завершает приложение. Обработчики Play/Pause
пока используют существующий GUI-путь; перед подключением MediaPlayer требуется
идемпотентный Pause в аудиопотоке, чтобы исключить гонку между чтением состояния
и командой переключения.

## Проверенные точки расширения (Slint 1.18.1 / winit 0.30.13)

- Slint предоставляет `BackendBuilder::with_window_attributes_hook`,
  `with_custom_application_handler` и `with_default_menu_bar(false)`.
- Обработчик Slint не предоставляет отдельного события повторного открытия Dock.
- В `winit/src/platform/macos.rs`, раздел Custom NSApplicationDelegate,
  документирована регистрация собственного делегата: эта версия winit сама
  делегат не регистрирует. На следующем этапе необходимо проверить фактический
  делегат NSApplication и сохранить его время жизни; нельзя молча заменить
  делегат, поставленный другой библиотекой.
- Slint создаёт стандартное меню через muda. При добавлении своего меню нужно
  отключить стандартное; Slint-компонент MenuBar также может заменить меню.

AppKit, MediaPlayer и ServiceManagement bindings добавляются по мере реализации
соответствующих модулей menu.rs, media.rs и автозапуска. На подготовительном
этапе напрямую нужен только objc2 с MainThreadMarker. Все платформенные
зависимости остаются в секции cfg(target_os = "macos") Cargo.toml.

Проверки: `cargo clippy --release --all-targets --locked -- -D warnings`,
`cargo test --release --locked`, `cargo build --release --locked`.
